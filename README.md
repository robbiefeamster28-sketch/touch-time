# Touch Time – Soccer Drills

A single-page soccer training app: drills, practices, timed tests with medals, goals, levels and badges. Progress is saved in the browser.

Open `index.html` in a browser to use it.

Outside claude.ai, progress (time logged, test results, favorites) is saved in the browser's local storage. Cloud sync and drill video uploads only work when the page runs as a claude.ai artifact.
